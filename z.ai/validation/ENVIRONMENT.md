## Daemon configuration (`lab/run/OoklaServer.properties`)

- `OoklaServer.tcpPorts = 8080`, `OoklaServer.udpPorts = 8080` (**port 8080 only** — lab constraint)
- `OoklaServer.useIPv6 = true` → listens on `0.0.0.0:8080` + `[::]:8080` (TCP & UDP)
- `openSSL.server.certificateFile/privateKeyFile` = lab cert pair (custom certs disable Let's Encrypt)
- `openSSL.server.minimumTLSProtocol = 1.2`
- `OoklaServer.enableAutoUpdate = false` (pin the tested version)
- `OoklaServer.clientAuthToken.denyInvalid = true` (default)
- Console + File logging, **access log enabled** (`logging.loggers.access.*`) for cross-validation evidence
