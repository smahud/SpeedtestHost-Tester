Ookla Server Tester

Use this tool to ensure that your Ookla Server is publicly available and properly configured. The Server Tester will verify that the Ookla Server daemon is accepting connections, as well as validate the legacy HTTP upload script, latency file, download image files, and required server settings like KeepAlive.

OoklaServer / Netgauge TCP

Clone alat resmi Ookla Server Tester — tanpa captcha & banner, berjalan sepenuhnya dari browser Anda dengan alur test identik: netgauge TCP/WebSocket (HI, PING, DOWNLOAD, UPLOAD), HTTP legacy (crossdomain.xml, /hi, upload.php, random*.jpg, latency.txt), HTTPS, dan KeepAlive.
Jika peramban memblokir koneksi langsung (halaman dibuka via https), unduh file ini lalu buka langsung (klik ganda) atau sajikan via http:// — atau gunakan versi CLI.
