# DECISIONS.md — architectural decisions that must be preserved

Each decision lists the alternatives that were considered and the reason for
the choice.  A future session must not silently reverse any of these.

---

## D-01 — The Host Tester is a *diagnostic*, not a speedtest engine

**Decision.** The implementation runs the 19 server-side configuration checks
and reports PASSED/FAILED.  It does not measure bandwidth, latency percentiles
or packet loss.

**Why.** that is what Ookla's Server Tester does; the name "Host Tester" is
misleading.  The official Speedtest CLI *is* a benchmark and is used as the
reference client, never as an oracle for the diagnostic verdict.
**Rejected.** adding throughput measurements — they would measure the runner,
not the server.

## D-02 — The legacy fallback port defaults to 80 and is overridable

**Decision.** `--legacy-port` (default 80) because the original tester derives
port 80 from the hostname.  The official daemon also serves the legacy paths
on 8080, so the port must be selectable.

**Evidence.** `lab/results/probe-http.json` — the daemon serves
`/crossdomain.xml`, `/speedtest/latency.txt`, `/speedtest/upload.php` and the
ten images on its own port.

**Rejected.** hardcoding 8080 (breaks the original semantics) and dropping
the legacy section (loses six checks).

## D-03 — Both upload size algorithms are supported, `auto` is the default

**Decision.** `--upload-mode auto|legacy|native`, reporting `detected_mode`.

**Why.** the legacy PHP endpoint computes `500 + Σ(len(key)+len(value)+3)`;
the official daemon returns the raw `Content-Length`.  `auto` accepts either
and says which one matched, so the report is never silently wrong.
**Rejected.** picking one algorithm (it would produce false failures against
real servers of the other kind).

## D-04 — TLS verification is never disabled

**Decision.** `ssl.create_default_context()` everywhere; `--ca-bundle`
*replaces* the trust store exactly like the official CLI's
`--ca-certificate`.  An untrusted chain yields a `FAILED` row that also
carries a diagnostic `insecure_response` line, which can never turn the row
into `PASSED`.

**Rejected.** an `--insecure` switch — it would let a broken server look
healthy, and the brief forbids treating an insecure connection as a
validated HTTPS success.

## D-05 — The daemon port is probed in plain TCP; HTTPS is a separate probe

**Decision.** by default the NetGauge/WebSocket/crossdomain probes use plain
TCP on the daemon port and the `https` probe uses TLS on the *same* port.

**Why.** the official daemon performs protocol sniffing and serves both on
one port; the official CLI also uses its plain TCP suite even against a
TLS-enabled daemon (verified in `CROSS_VALIDATION.md`).
**Consequence.** `https://host:8080` as an *input* now selects TLS for the
daemon probes (F-09), because a user who writes `https://` means it.  The
override flags exist for the cases where that is wrong.

## D-06 — Private and loopback addresses are opt-in

**Decision.** non-global addresses are removed from the candidate list unless
`--allow-private` / `allow_private=1` is given.  The web form does not
expose the flag.

**Why.** the service is reachable by anyone who can reach the port; it must
not become an SSRF proxy into the internal network (F-03).

## D-07 — The laboratory lives in `lab/`, the documentation in `validation/`, the tests in `tests/`

**Decision.** `lab/{binaries,cli,config,certs,scripts,logs,results,runtime}`,
`validation/` with the eleven mandated documents, `tests/` with the suite.

**Why.** the audit brief prescribes this layout; it also keeps the previous
session's flat `ooklaserver/sim/` tree from growing two parallel histories.
**Migration note.** the previous session's `ooklaserver/sim/` content was
archived under `lab/results/previous-session/` — it is historical evidence,
not live configuration.

## D-08 — The official binaries are downloaded and hash-verified, never committed

**Decision.** `lab/scripts/download-official.sh` fetches the daemon and the
CLI and refuses to continue when the SHA-256 does not match the recorded
value.  `arena.ai/.gitignore` excludes them.

**Why.** the brief forbids committing proprietary binaries, and the
pre-commit checklist requires checking for them.

## D-09 — The laboratory is self-contained

**Decision.** the legacy control server generates the ten image files
locally with the exact official byte sizes and implements the legacy PHP size
formula itself.  The laboratory PKI is generated by
`lab/scripts/make-certs.sh`, including three negative certificates.

**Why.** the previous laboratory downloaded a 95 MB archive from an
unrelated third-party mirror (F-15).  A laboratory must not depend on an
unverified external host for its fixtures.

**Honesty rule.** the control server is labelled a **control**, not the
official package, and the byte sizes it uses were independently
re-confirmed against the genuine daemon.

## D-10 — The official CLI cross-validation never publishes a result

**Decision.** `results.speedtest.net` is redirected to a local stub that
records the upload and answers **503**; the CLI reports `persisted: false`.

**Why.** a loopback measurement published as a public speedtest result would
be a false record.  The brief explicitly forbids it.

## D-11 — The host tester's own verdict and the official CLI's verdict are kept separate

**Decision.** a successful CLI benchmark never implies that the diagnostic
verdict is correct; the two are compared layer by layer in
`CROSS_VALIDATION.md` and classified as *verified equivalent* /
*functionally compatible* / *different by design* / *not independently
verifiable*.

## D-12 — The 1:1 form contract is preserved

**Decision.** the original DOM structure, the original CSS, the original
`POST /host-tester` contract and the field name `ookla-server` are kept.
reCAPTCHA, advertising/consent banners, analytics and every external asset
stay removed.

**Why.** it is the core requirement of the submission.  Advanced options are
passed as additional query/POST parameters so that the markup does not have
to change.

## D-13 — No CSRF token is added to the form

**Decision.** none.

**Why.** the original page has none; inventing one would break the 1:1
contract.  The action is a read-only diagnostic against a third-party host
and carries no session state, so the residual risk is accepted and recorded
in `SECURITY_AUDIT.md` §4.

## D-14 — The implementation depends on the Python standard library only

**Decision.** no third-party package, anywhere.

**Why.** the project has to stay independently executable when it is copied
out of the multi-agent repository, and the laboratory must run in a minimal
container.

## D-15 — The HTTP result page is an approximation, and says so

**Decision.** the result layout follows the public result schema; the page
carries `runner_note` ("Checks are executed from this sandbox, not from
Ookla's regional watchdog servers") and `cross_validation_note`.

**Why.** the official result page is behind reCAPTCHA and was never observed.
Claiming byte equality would be false.

## D-16 — One daemon instance at a time, enforced

**Decision.** `start-daemon.sh` refuses to start when port 8080 is already
bound, and `cross-validate-cli.sh` stops any running daemon before it starts
its own.

**Why.** OoklaServer binds its data plane with `SO_REUSEPORT`, so a second
instance silently shares the port and the kernel distributes connections
between the two daemons.  Every measurement taken in that state is
non-deterministic — and a "flaky" result is worse than a missing one.
The daemon also **ignores `SIGTERM`**, so `stop-daemon.sh` escalates to
`SIGKILL`.

## D-17 — The control-plane stub runs unprivileged inside the namespace

**Decision.** in the `real` scope the stub is started with `sudo -n` (port 443
is privileged); in the `isolated` scope it is started **without** sudo.

**Why.** inside `unshare -rn` the process is uid 0 with a full capability set
over that namespace and can bind port 443 directly — while `sudo` cannot run
there at all (`unable to open /etc/sudoers`).  Using sudo in the namespace
silently produced a broken experiment (F-22).
